# backend フォルダ：関数一覧

## app.py

| 関数名 | 処理 |
|---|---|
| read_settings | 保存済みフォルダ設定を読み込み、未設定時の初期値を返す。 |
| resolve_image_path | 指定ルート内のパスを解決し、存在と画像・フォルダの種類を検証する。 |
| image_dimensions | EXIF回転を反映した画像寸法を取得し、更新日時とサイズでキャッシュする。 |
| health | サーバーの識別情報と起動状態を返す。 |
| get_settings | 設定、PCからの変更可否、LAN接続用URL、対応形式を返す。 |
| save_settings | PCから入力されたフォルダを検証し、UTF-8 BOMなしで設定を保存する。 |
| browse | 直下のフォルダと画像を自然順で列挙し、寸法・更新情報・読めない画像を返す。 |
| original_image | 元画像をブラウザ内で表示する形で配信する。 |
| thumbnail | 回転補正したWebPサムネイルを生成・キャッシュし、同時生成を制御して配信する。 |

## launcher.py

| 関数名 | 処理 |
|---|---|
| open_when_ready | サーバーの起動完了を待って、PCのブラウザを開く。 |
| main | オプション・ビルド・ポートを確認し、開発用または通常用サーバーをLAN向けに起動する。 |
