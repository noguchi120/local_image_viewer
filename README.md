# Local Gallery

PC内の画像フォルダを、PCや同じWi-Fiのスマホブラウザから閲覧するアプリです。
Vue / TypeScript / Vite、PhotoSwipe、FastAPI、Pillowで構成しています。

## 起動

1. 初回だけ `setup.cmd` をダブルクリックします。ライブラリの取得にはインターネット接続が必要です。
2. `start.cmd` をダブルクリックすると、サーバーが起動して **http://localhost:8000** が開きます。
3. PCの画面で、閲覧するフォルダの絶対パスを入力します。エクスプローラーのアドレスバーからコピーできます。
4. スマホをPCと同じWi-Fiへ接続し、「スマホで開く」のQRコードを読み取ります。

必要な環境は **Python 3.12以上（またはuv）とNode.js 22 LTS以上**です。
初回セットアップ後、通常の閲覧ではNode.jsやインターネット接続を使いません。
セットアップ済みなら `start.cmd` だけで使えます。未セットアップの場合は初回起動時に必要な準備を行います。

サーバーのウィンドウは起動したままにしてください。終了するには、そのウィンドウで `Ctrl+C` を押します。
PCがスリープ中やサーバー停止中はスマホから閲覧できません。

## 操作

- フォルダを押すと中へ移動。「上のフォルダ」やパンくずで戻れます。
- 画像はサムネイルの一覧で表示します。タップすると原寸画像を使った拡大ビューアーが開きます。
- 拡大ビューアーでは左右スワイプで前後の画像へ移動、ピンチやダブルタップで拡大・縮小できます。
- PCでは左右矢印キーで移動、Escapeでビューアーを閉じられます。
- ファイル名検索・名前順・更新日時順の並び替えに対応しています。スワイプ順も表示中の一覧に従います。
- ファイルを追加・変更した場合は一覧の更新ボタンを押してください。
- フォルダ設定はPC自身のlocalhost画面から変更します。設定は次回起動時にも残ります。

対応形式：JPEG / PNG / WebP / GIF / BMP / AVIF。GIFの一覧サムネイルは静止画、拡大表示では元ファイルを表示します。
HEIC・RAW・TIFFには対応していません。AVIFなどの表示可否はスマホのブラウザにも依存します。

## スマホから接続できない場合

- スマホでは `localhost` ではなく、画面の接続先（例：`http://192.168.1.20:8000`）を開きます。
- Windowsのファイアウォールで、Pythonのプライベートネットワーク通信を許可してください。
- 接続先が複数出る場合、Wi-FiのIPv4アドレスを選択してください。VPNなどの接続先が含まれる場合があります。
- ゲストWi-Fiや端末間の通信を禁止するWi-Fi設定では接続できません。

指定フォルダとそのサブフォルダの画像を、接続できるLAN内の端末に配信します。ログイン機能はありません。

## 開発

`develop.cmd`：FastAPI（8000）とVite（5173）を起動します。開発画面は **http://localhost:5173** です。
Viteが `/api` をFastAPIへ中継します。通常利用では、ビルド済みの画面もFastAPIが配信するため、起動するサーバーは1つです。

`build.cmd`：画面の変更後に実行します。ビルド後は通常利用のサーバーを再起動してください。
依存ライブラリを変更した場合は、`npm install` と `setup.cmd` を実行します。

サーバーだけをブラウザを開かず起動する場合：

```powershell
.venv\Scripts\python.exe -m backend.launcher --no-browser
```

テスト：

```powershell
uv pip install --python .venv/Scripts/python.exe -r requirements-dev.txt
.venv\Scripts\python.exe -m unittest discover -s tests -v
npm run build
```

設定は `data/settings.json`、生成サムネイルは `data/thumbnails/` に保存します。
サムネイルは元画像のパス・更新日時・サイズごとに再生成し、元画像は変更しません。
キャッシュを消す場合はサーバー停止後に `data/thumbnails/` を削除できます。
関数一覧は `docs/pg/` にまとめています。
